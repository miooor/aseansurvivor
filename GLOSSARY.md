# Campaign vocabulary

| Term | Meaning in this game |
| --- | --- |
| Survivor | The playable character chosen for a run. **Hero** is the same character in code and save data. Keep stable hero IDs when display names change. |
| Chapter | A country in the campaign. Malaysia is playable. Thailand is a planned chapter. Use *stage* for an individual playable atlas stop. |
| Route | An ordered path through stages in a chapter. Malaysia’s West Coast and East Coast routes share Johor. A route is complete when every stage on it has a recorded clear. |
| Stage | A playable location selected before a run, such as Melaka. Access permits a start. A clear records a victory. |
| Destination | An in-stage place the survivor can travel to. For an authored activity, the destination marker identifies where to go and the encounter or quest describes what to do there. Caches have their own rewards. |
| Encounter | One of Johor’s three optional activities, such as Lantern Ward. Older specs also call these *events*. |
| Quest | The authored regional activity in each Malaysian stage beyond Johor. Its objective can lead through several sites. |
| Reward | What the player receives for an action. An encounter or quest completion grants an equipment offer. A cache can grant other benefits. |
| Offer | A set of equipment choices presented together. The player can equip one item or skip. Authored activities specify a slot. An elite chest can offer several slots. |
| Loot | A collective term for drops and rewards. Use *offer* for the choice and *equipment* for the items the survivor wears. |
| Equipment | Items worn in named slots for the current run. Choosing a replacement discards the previous item in that slot. Purchased survivor upgrade ranks persist across runs. |

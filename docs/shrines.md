# Shrine blessings

Walk over a shrine to activate its emblem above your health bar. Each blessing lasts 12 seconds of play. Picking up another shrine starts a fresh 12-second timer with its effect.

| Shrine | Blessing |
| --- | --- |
| Monsoon | Move 35% faster. |
| Tiger | Deal 30% more damage. |
| Kingfisher | Deal 60% more damage to full-health foes. |
| Crocodile | Deal 75% more damage to foes at or below 25% HP. |
| Banyan | Deal 50% more damage to bosses and elites. |
| Cinder | Double damage over time. |
| Morning Star | Gain 35 percentage points of critical chance. |
| Prism | Critical hits deal triple damage. |
| Bronze Drum | Basic attacks recharge 60% faster. |
| Cicada | Active skills recharge 50% faster. |
| Gong | Gain double ultimate charge from ordinary kills. |
| Hot Spring | Recover 3% of max HP per second. |
| Orchid | Recover 2 HP per ordinary kill. |
| Turtle Shell | Take 35% less damage. |
| Mountain Mist | Gain 0.8 seconds of protection after taking a hit. |
| High Tide | Double ember and coin pickup radius. |
| Firefly | Gain 50% more XP from embers. |
| Harvest | Collected coins are worth twice as much. |
| Mountain Frost | Direct hits slow ordinary foes for 2 seconds. |
| Hornbill | Direct hits push ordinary foes away. |
| Pepper Vine | Deal 50% more damage within 100 units. |
